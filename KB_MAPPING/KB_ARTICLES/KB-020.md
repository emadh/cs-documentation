## Content requirements

Concepts:
- Page size is 50.
- Product Number cannot be unchecked.
- Select all means every product in the account, not the current location or search.
- Printable view does not call print by itself.

Prerequisites and permissions:
- Signed in. Some toolbar buttons are absent for read-only.

Customer actions:
1. Open Products.
2. Click column headers to sort. Click again to reverse.
3. Use SAVE COLUMNS after showing or hiding columns.
4. Select the page, then Select all only if you mean the whole catalog.
5. Use Add, export, print barcodes, or printable from the toolbar. Delete and multi-edit have their own articles.

Options and settings: Default sort is product number ascending. Cost value is calculated.

Expected results: Column choices are per user.

Errors and troubleshooting: “No products yet”. “No matches found!”

Limitations:
- The SQL page size grows on later pages, so a later page can show more than 50 rows. Mention this only if the live grid does it.
- A cell that is only a web address becomes a link and does not open the editor.

Example: Hide Sell Price, sort by quantity, select this page only.
