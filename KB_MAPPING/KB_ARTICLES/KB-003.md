## Content requirements

Concepts:
- Types are Building, Warehouse, Store, Floor, Room, Closet, Shelf, Bin, and Vehicle.
- New locations default to Building when the type is missing, and parent All Locations.
- Type cannot be changed later.

Prerequisites and permissions:
- Signed in, not read-only. Map unlocked is not required to create.

Customer actions:
1. Click the floating +.
2. Pick a type.
3. Name it. The suggested name is New plus the type.
4. Save.
5. Click + on that tile to add a child.

Options and settings: Nine location types. Default name New {type}.

Expected results: A location is created. Activity records a location create. Inventory does not move.

Errors and troubleshooting: “That location name is already in use!” Empty-map coaching can swallow the floating + click.

Limitations:
- No control was found to change type after create.
- Mobile create only allows a top-level parent.

Example: Add a Room named Office, then a Shelf named A1 inside it.
