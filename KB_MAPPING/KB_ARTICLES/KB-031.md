## Content requirements

Concepts:
- This mode does not insert products.
- Match by product number, description, or a custom field.
- More than one match is skipped.
- Check-in keeps the file quantity. Check-out and transfer cut it to on-hand.
- The page locks until save or cancel.

Prerequisites and permissions:
- Signed in, not read-only. Import before the destination selection is filled.

Customer actions:
1. Open check-in, check-out, or transfer.
2. Click import.
3. Map the columns. Transfer files use FROM and TO.
4. Review skips and reductions.
5. Save or cancel.

Options and settings: Samples: Product Number and Quantity. With a location, add Location. Transfer adds FROM and TO.

Expected results: Save uses that mode’s activity. An unedited import tags the comment. Cancel writes nothing.

Errors and troubleshooting: Quote the file and row errors from XFR-005, including “This value matched more than one product” and “This product was not found at the source location.”

Limitations:
- The Start page can consume a similar file and then add or subtract. Say so if you mention Start. Do not treat it as the Transfer overwrite.

Example: A checkout file of SKU and quantity against one bin.
