## Content requirements

Concepts:
- Quantity is available only when a real location is selected, and it overwrites. It does not add.
- Empty value is rejected.
- Presets are enforced unless the value is empty or Other (Specify).
- Select all edits the whole account.

Prerequisites and permissions:
- Signed in, not read-only. A selection.

Customer actions:
1. Select products. Avoid Select all unless you mean every product.
2. Open For All Selected Items.
3. Choose a field, enter a value, and set it.

Options and settings: Fields: Product Name, Quantity at a real location, Buy Price, Sell Price, and each custom field.

Expected results: Those products change. Activity records a product edit with quantity 1 in the log, not the number you typed.

Errors and troubleshooting: “Please enter a value”. “Value must be numeric!” “Value is not allowed for this field.”

Limitations:
- Do not say quantity is added to the current amount.

Example: Set Supplier to Acme for the five selected gloves.
