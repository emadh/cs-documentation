## Content requirements

Concepts:
- Product photos in the list depend on the display setting.
- There is no size or type check on the product photo upload.
- Label stocks are 30252 (default), 30336, 30334, and 30330.
- Location barcodes are edited in the location editor. Product labels are printed from the product.

Prerequisites and permissions:
- Signed in. Read-only can download attachments and cannot upload.
- List photos require the product-images setting.

Customer actions:
1. Open a product and click the image.
2. Use the paperclip to attach or download a file. Confirm before delete.
3. Select products and print barcodes. Choose a stock size. Preview.
4. Turn on product images in Settings if the grid should show photos.

Options and settings: Default stock 30252, 1-1/8 by 3-1/2 inches. Code 128. Missing name prints as UNTITLED.

Expected results: Image or file stored. Print does not write the database.

Errors and troubleshooting: Attachment delete confirm: “Are you sure you want to delete this attachment?”

Limitations:
- A Lansweeper image disables product upload.
- Select-all print asks before printing every product.
- The printable list does not send the job to the printer by itself.

Example: Print 30336 labels for five selected SKUs.
