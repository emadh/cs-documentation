## Content requirements

Concepts:
- Cost value is quantity times buy price. It is not stored.
- The currency symbol is account-wide free text, default $.
- The subscription card does not use this symbol.
- Buy and sell can be hidden per user.

Prerequisites and permissions:
- Signed in. Prices hidden for records accounts.

Customer actions:
1. Set the currency symbol in Settings if you are an admin.
2. Show Buy Price and Sell Price. That Settings control appears only while personalized sort is on.
3. Read Cost Value in the grid and in the report.

Options and settings: Image URL is an optional report column, off by default.

Expected results: Display and a calculated column.

Errors and troubleshooting: “Please enter a currency symbol”.

Limitations:
- Do not say cost is a stored field.
- Do not say the currency symbol changes billing.

Example: Buy 2, quantity 10, cost value 20.
