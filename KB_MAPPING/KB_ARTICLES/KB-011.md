## Content requirements

Concepts:
- Desktop zoom defaults to 1 and stays between 0.1 and 1.
- Touch zoom defaults to 0.74 and can go up to 2.2.
- Keys + and - multiply by 1.1 or 0.9.
- ABC sort orders children by name. It does not change inventory.

Prerequisites and permissions:
- Signed in.

Customer actions:
1. Click + or - or pinch.
2. Drag empty canvas to pan. Use Scroll to map origin when you are away from the top left.
3. Type in Search Map, press Enter to cycle matches, Escape to clear.
4. Open the minimap and click it to scroll.
5. Turn ABC sort on from the map controls if children should be alphabetical.

Options and settings: Minimap is 240 by 160 and can auto-open. Narrow layout uses the mobile zoom.

Expected results: This user’s view and, for ABC sort, this user’s display order.

Errors and troubleshooting: Empty search disables quantity-report download with “No results to download”. API search failure falls back to matching location titles.

Limitations:
- Which fields the map API matches is Uncertain. Do not list fields beyond the title fallback.

Example: Zoom out, find “Dock” with Search Map, then jump back with the minimap.
