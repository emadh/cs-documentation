## Content requirements

Concepts:
- Check-in adds. Check-out removes from a place. Transfer moves between two places.
- There is no Adjust action on Transfer or Start.
- Start writes stock before it asks for a comment. Transfer asks as part of save.
- Start check-out subtracts and stops at 0. Transfer check-out sets the source to the quantity you left behind.

Prerequisites and permissions:
- Signed in, not read-only. The Start menu hides when the account has no products.

Customer actions:
1. Open Start.
2. Choose Check In, Check Out, Transfer, Create, or Quick Scan.
3. Pick locations. The same place twice on a transfer says “The Source can't be the Destination!”
4. Finish. Then, if you want, save a comment. That comment is a second write.

Options and settings: A query can open check-in, check-out, transfer, or add directly.

Expected results: Stock changes before the comment box on Start.

Errors and troubleshooting: A missing location cookie exits without saving. Zero products: “You have not added any products yet”.

Limitations:
- Do not tell readers the Start page and the Transfer page update quantities the same way.

Example: Use check-in when goods arrive, check-out when they leave, transfer when they move from one shelf to another.
