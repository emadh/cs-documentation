## Content requirements

Concepts:
- Read-only peek can download files and print. It cannot edit the barcode or upload.
- A duplicate barcode turns the box red and does not save.
- Kiosk links are covered in their own article.

Prerequisites and permissions:
- Editor: not read-only. Peek: signed in.

Customer actions:
1. Open the location editor.
2. Change the name.
3. Use the paperclip to attach a file. Delete asks “Are you sure you want to delete this attachment?”
4. Scan or type a barcode and press Enter.
5. Use Print Barcodes if needed.

Options and settings: Barcode label is “Barcode # (scan to change)”.

Expected results: Name, file, or barcode saved on that location.

Errors and troubleshooting: Duplicate barcode: red box, no alert. Duplicate name: “That location name is already in use!”

Limitations:
- All Locations is not editable.
- A Load Type other than EXISTING creates immediately. The map always sends EXISTING. Do not tell users to change Load Type.

Example: Attach a floor plan PDF and set the room barcode.
