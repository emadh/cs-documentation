## Content requirements

Concepts:
- The manager appears only for beta accounts.
- The plaintext key is shown once.
- The docs link is visible even when you cannot create a key.
- OAuth consent is a different mechanism. Do not mix them. Do not list OAuth scopes.

Prerequisites and permissions:
- Signed in. Beta list for create and delete.

Customer actions:
1. Open API & Integrations.
2. If you see the request sentence, email support. The docs link still works.
3. If you see keys, enter a name and click + Create New API Key.
4. Copy the prompt text.
5. Delete a key only if you mean to revoke it immediately.

Options and settings: Names longer than 30 characters display with an ellipsis.

Expected results: A key or a revocation.

Errors and troubleshooting: “Please enter a valid key name”. “Error creating API key. Please try again.” Non-beta text tells you to email support@cyberstockroom.com.

Limitations:
- Do not document a direct CreateNewKey call as a customer path for non-beta accounts.

Example: Create a key named Warehouse iPad and store it in a password manager.
