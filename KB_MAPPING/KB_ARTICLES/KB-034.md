## Content requirements

Concepts:
- There is no undo.
- Default is all activity, all users, all locations, last 90 days, 15 rows.
- A comment in the code says 365. The product uses 90.
- Show More reloads a longer list from the top and can stay visible when everything is shown.

Prerequisites and permissions:
- Signed in.

Customer actions:
1. Open Activity.
2. Read a row. Click it for details.
3. Click a product or location name in the row to open that editor instead of the details.
4. Use the header icon for up to five recent inventory rows, then View Activity History.

Options and settings: Empty text is “No Activity...”. Your own name shows as You when it matches.

Expected results: A record. Nothing is reversed.

Errors and troubleshooting: Missing detail: “Activity not found”.

Limitations:
- With a user filter, timestamps may not use the account time zone. Mention this only as a limitation.
- The header popup’s other-user suffix is a user index, not a name. Do not describe it as the person’s name.

Example: Find yesterday’s check-in and open the product from the row.
