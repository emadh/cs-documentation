## Content requirements

Concepts:
- Suggestions come from an outside search API, limit 10.
- A product opens the editor. A location opens the location editor.
- Enter stores the text and opens the product list.
- If nothing comes back and Add is allowed, one row offers Create New Product.

Prerequisites and permissions:
- Signed in. The create row is hidden for read-only.

Customer actions:
1. Click the header search.
2. Click a product or location suggestion.
3. Or press Enter to search the product list.

Options and settings: No search operators.

Expected results: Navigation only, unless you then edit.

Errors and troubleshooting: An HTTP error shows no create row.

Limitations:
- Do not say which fields the suggestion API matches.

Example: Type a SKU, click the product, land in the editor.
