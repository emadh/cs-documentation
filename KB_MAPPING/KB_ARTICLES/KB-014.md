## Content requirements

Concepts:
- Sharing copies coordinates, zooms, and vertical or 3D stacks. It does not copy inventory.
- Only an admin can turn sharing on.
- An invite copies coordinates with the share marker stripped.

Prerequisites and permissions:
- Admin for the switch. Any signed-in user can sync.

Customer actions:
1. In Settings, under Options, turn Share Map Layout on.
2. As another user, open the map gear, then Shared Maps.
3. Pick a person. Read the warning that your layout will be lost.
4. Click Sync, or Keep my layout.

Options and settings: Default sharing is off.

Expected results: The other user’s layout is replaced only if they click Sync.

Errors and troubleshooting: “No shared maps. Admins can share their maps in the Settings page.” “Could not load shared maps.” “Could not save the synced layout. Please try again.”

Limitations:
- Teammates cannot edit the shared original.

Example: An admin arranges the building. A new hire syncs to that layout.
