## Content requirements

Concepts:
- Create import and movement import are different.
- Create import rejects duplicate numbers in the file and does not update existing products.
- Movement import skips ambiguous matches and missing stock. It does not create products.
- Limits: under 250 KB, 100 columns, UTF-8, commas, header row.

Prerequisites and permissions:
- The file and the mode you used.

Customer actions:
1. Read the error title: Success, Import Failed, or No items imported.
2. If the file was rejected, fix size, encoding, semicolons, or quotes.
3. Map a product number.
4. For a movement, open the skipped rows and fix duplicates or quantities.

Options and settings: Movement match can be product number, description, or a custom field.

Expected results: A corrected file can be imported again. Cancel on the review screen writes nothing.

Errors and troubleshooting: Use the exact strings in PED-012 and XFR-005. Do not paraphrase a sentence you cannot see.

Limitations:
- Do not invent skip reasons that were not quoted.
- Existing products are not updated by a create import. Say that when the user expected an update.

Example: A semicolon export from another tool is rejected. A name that matches two products is skipped.
